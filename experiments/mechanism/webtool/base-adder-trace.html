Five solved examples, then your problem. Answers are written backwards (ones digit first).

Every number comes from running the trained weights in your browser. The carry threshold (about half the base) and the stop positions are rules from the study's report: they describe the model well, but they are summaries, not code inside it.

Glossary

Token: one character of the prompt (a digit, +, = or a line break). The model reads tokens left to right and predicts the next one.

Layer: this model has 2. Each layer has 4 attention heads and an MLP of 256 neurons.

Attention head (LxHy): head y in layer x. From one token it looks back at earlier tokens, weighting them by attention (the weights add up to 1).

Neuron: one unit of an MLP layer. It takes a weighted sum of its inputs (its input) and applies GELU, a smooth version of max(0, x) (its output).

Logit: the model's score for each possible next token. The highest one is what it writes.

Vote: how much one neuron raises the written digit's logit above the average digit's (direct logit attribution).

Column k: answer digit k, counting from the ones digit (column 0).

Very small numbers, like 0 + 0 or 8 + 7 in binary, are rare in training, and the model sometimes gets them wrong. Those are the model's own mistakes.
